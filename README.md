# infosec-learning-notes

90 天自学网络安全与漏洞挖掘路线

目标：
- 零基础入门
- 每天 2 小时
- 以漏洞挖掘 / Web 安全 / 攻防实操为主
- 90 天后能掌握基础渗透/漏洞利用思路，并有多个 writeup

参考路线：
- Hamed233/Cybersecurity-Mastery-Roadmap
- jassics/cybersecurity-roadmap
- jaspreet-infosec/TryHackMe-Roadmap

仓库结构：
- notes/        学习笔记
- writeups/     练习记录、靶机 Writeup
- tools/        小脚本、payload 模板、速查文件
- tasks/        每周计划与打卡记录

学习原则：
- 只在授权环境中练习
- 每次做题都写 writeup
- 每周至少提交一次仓库更新
- 先做 Web 安全与基础实战，再扩展其他方向

每日节奏：
- 1 小时：阅读/复盘/看基础知识
- 1 小时：实操（靶机、工具、题目）
- 结尾 15–20 分钟：记录笔记 / 上传结果

学习顺序建议：
1. Linux 基础
2. 网络基础
3. 信息收集 / 枚举
4. Web 安全（XSS / SQLi / 文件上传 / LFI/RFI）
5. Burp Suite / nmap / ffuf / sqlmap
6. 反弹 shell / 简单后渗透 / 提权
7. 完整靶机实战
8. CTF 与漏洞挖掘复盘
