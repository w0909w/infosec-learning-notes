# 学习计划（90 天）

第 1 周：Linux + 基础命令
- 学习 Linux 文件系统、权限、用户与组
- 掌握 grep、awk、sed、find、chmod、sudo
- 完成一个入门级 TryHackMe 房间

第 2 周：网络基础
- TCP/IP、UDP、HTTP、DNS
- 了解三次握手、端口、协议
- 用 Wireshark 做抓包演示

第 3 周：信息收集与枚举
- nmap
- ffuf / dirsearch
- SecLists 使用
- 记录扫描方法与结果

第 4 周：Web 安全基础
- OWASP Top 10
- XSS
- SQLi
- CSRF

第 5–6 周：深入 Web 漏洞
- 反射型/存储型 XSS
- 布尔/时间/报错型 SQLi
- 文件上传
- 文件包含（LFI/RFI）
- Burp Suite 使用

第 7 周：认证与会话
- 登录绕过
- Cookie / Session 处理
- 突破认证逻辑

第 8 周：完整流程实战
- 从信息收集到利用
- 从漏洞到 shell
- 练习一台靶机并写 writeup

第 9 周：反弹 shell / 后渗透
- netcat / nc
- 反向 shell
- 简单权限提升

第 10 周：提权
- Linux SUID
- 弱权限
- Windows 基本提权思路

第 11 周：完整靶机实战
- 选择一台初级靶机
- 完成完整流程并写文档

第 12 周：CTF / 练习题
- Web 题
- 简单 CTF 训练
- 归档常用 payload

第 13 周：复盘
- 整理 3–5 篇 writeup
- 汇总成果
- 规划下一阶段
